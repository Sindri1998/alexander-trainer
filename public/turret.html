Sheet setup & troubleshooting
Columns: Tool, Insert, Insert location — a header row is detected by name, and without one the first three columns are used in that order.
Tab name pins the pull to one tab. Fill it in whenever the spreadsheet holds anything besides the library — tool reports, for instance — so other tabs can never be read into the tool list. Blank means the first tab.
The sheet must be readable without signing in: Share → Anyone with the link → Viewer. If Sync reports it was blocked, use File → Share → Publish to web, choose the tab, pick CSV, and paste that link instead.
